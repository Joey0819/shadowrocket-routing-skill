# Shadowrocket 分流与 AI 断线阻断

目标：国内网站与国内 AI 按规则直连；ChatGPT、Codex、Claude 等国外 AI 走选定代理；代理故障和重连期间，系统规则继续阻断受保护目标的公网直连。

此 Skill 提供维护方法、脱敏配置片段和经验，**不包含可直接安装的防火墙程序**。导入规则、启用 TUN、看到 VPN「已连接」，均不等于已实现系统级断线阻断。

## 确认实际状态

- 分清 Mac 与 iPhone。PF 与守护服务流程仅适用于 macOS；手机补充说明见 [references/operations.md](references/operations.md#iphone-与-tailscale)。
- 读取活动配置、全局路由、选中出口、代理链、实际监听端口、DNS 和系统阻断服务。历史 IP、端口和报告不能代替当前读回。
- 维护已有方案，保留出口 B、上游 A 及 fallback、所有端口、其他订阅、Hosts 和重写。用户明确要求修改其中一项时，仅改变该项。
- 先备份活动配置；系统修改另行备份本方案安装文件与 anchor。应用可能轮换副本名称，备份后确认。

## 应用内分流

按目标合并 [assets/routing-fragment.conf](assets/routing-fragment.conf)，去重并替换已有键；不要整份覆盖用户配置。

1. 国外 AI 的域名及鉴权、静态资源、上传、实时连接依赖优先 `PROXY`，不能含 `DIRECT` fallback，也不能排在国内通用规则之后。
2. 微信内容/图片、网易等国内服务的明确域名使用 `DIRECT`，配合国内加密 DNS；按实际故障补齐配套域名。主页响应不能证明远控或文章恢复。
3. 保留既有明确代理规则；随后按用户范围使用 `.cn`、`GEOIP,CN,DIRECT`，最终 `FINAL,PROXY`。域名与 GEOIP 分类不是实际地理位置保证。
4. 普通 DNS 与直连 DNS 使用可达的国内 DoH，避免未列出的国内域名先依赖故障代理。`dns-server` 参与 IP 规则匹配的解析；`direct-dns-server` 仅覆盖明确直连域名。
5. 代理类请求通常由代理端解析。`proxy-dns-server` 用于节点域名解析，不能误作「AI 专用 DNS」。先核对版本语义再改。
6. 保持 `udp-policy-not-supported-behaviour = REJECT`。本例保留 `dns-direct-system = false` 与 `dns-direct-fallback-proxy = false`，不引入额外系统解析和回退。
7. 保存、读回差异、编译成功，并确认「全局路由 → 配置」与活动文件勾选。保存成功不代表生效。

## 系统阻断与节点更新

先读 [references/operations.md](references/operations.md#macos-系统保护)。以下是设计约束，不能直接替代经过核对的 PF 安装实现。

- 系统 PF 限制物理出口，只允许必要局域网通信、明确代理入口与国内目的地；境外公网默认拒绝，已知 AI 拒绝优先。TUN 与物理连接状态不能互相授权。
- 国内域名和 PF 的 IP 白名单可能不一致，尤其是境外 CDN/远控对端。定位具体地址与规则，不要关闭 PF、放开所有 443 或整个云厂商网段。
- 节点同步器只读取用户授权的精确来源目录；只同步必需非凭据元数据。结构/完整性不明确时保留旧规则并报告。
- 验证当前清单、地址和协议/端口，生成候选、冲突与语法校验后原子更新本方案规则；失败保留上次有效规则。A→B 链路中的 B 不得获物理直连例外。
- 切订阅不应替换活动分流配置。新入口未同步时应保持阻断；不能承诺任意新节点、未来版本或其他客户端自动兼容。
- 系统确实要求管理员权限时，说明用途并提供已审阅脚本的完整单行命令，用户自行在终端输入密码。不要索要密码或复用未经检查的私人脚本路径。

## 最少且有意义的验证

- **仅改国内 DNS/域名**：编译、读回活动配置，确认受影响服务实际恢复，并确认一个相关 AI 仍匹配代理。系统规则未改时明确说明没有重复故障抓包。
- **改 PF、链路、同步或客户端**：授权范围内检查物理出口，短时故障后恢复原节点并确认代理恢复；阻断证据与正常代理正向对照分别记录。
- HTTP 响应、测速、配置匹配、进程运行、用户确认、物理抓包是不同证据。HTTP 403 可能是鉴权/挑战；`198.18.0.0/15` 虚拟来源不能证明物理直连。
- 无全球 IPv6 上联时不宣称完整 IPv6 故障实测。启动早期、重启、睡眠恢复等场景只按证据报告。
- 关闭临时日志；说明修改、保留项、实际结果和未验证项。用户确认恢复后，不做无关测速或重复断网。
